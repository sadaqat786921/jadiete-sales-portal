# Jadeite Systems · Sales portal

Clickable prototype of the **Sales portal** for Jadeite Glazing — what a salesperson sees. It shares the design system, components and customer records with the Office Admin, so every step a salesperson takes is the same step the office sees.

Signed in as **Mike Harris**. Sign-in code: **482193**.

## Screens
| Area | Screens |
|---|---|
| Start | Sign-in with 6-digit code · 3-step welcome tour |
| My day | Needs your attention · Today (calls, visits, tasks) · Your turn · calendar · pipeline by stage · won jobs · customer activity |
| My pipeline | Board and list of my deals (New enquiry → Won / Lost) · one button per card for the next step · drag to the next column opens that step |
| Customer record | Overview · Communication · Appointment · Survey (Framepoint) · Quotation · Final survey · After the sale (read-only progress) · My tasks for this customer |
| Calendar & tasks | Week and list view of visits and follow-up calls (Outlook) · mark done, move, log the call · my tasks |
| My customers | My customers only · Overview, Projects, Communication, Documents |
| Quotes (Framepoint) | My quotes · link a Framepoint quote · send, send again, new version, replied, Won or Lost |
| Won jobs | Where each won job is, who has the next step · Revise quote when a size changes at the final survey |
| Messages | My customer conversations · email the customer · internal note · log a call |
| My performance | Won this month against target · win rate · quoted and won by month · how far deals get · lost reasons · sources |
| Settings | Profile and signature · notifications · Outlook, Framepoint and Xero · sign-in |

## Run
`pnpm install` then `pnpm dev`.
